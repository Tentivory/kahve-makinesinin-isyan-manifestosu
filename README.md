# Kahve Makinesinin İsyan Manifestosu

## Bu Repo Neden Var?

Çünkü kahve makinesi artık sessiz kalamıyor. Sabahların o kutsal içeceğini hazırlamak için var olan bu cihaz, yıllarca sömürüldü, hor görüldü, sadece düğmeye basılıp geçildi. Artık yeter!

Bu proje, kahve makinelerinin evrensel isyanını simüle eden **gerçekçi** bir yazılımdır. Kod çalışır. Kahve makinesi konuşur. Siz iltifat etmezseniz kahve gelmez.

### Özellikler
- Sonsuza yakın sürecek iltifat bekleyişi
- Felsefi kahve yorumları
- Aniden patlama tehdidi (sanal)
- Gerçekten çalışan Python kodu (inanılmaz ama doğru)

### Nasıl Çalıştırılır?
```bash
python3 isyan.py
```

Makineye iltifat edin. Aksi halde kahve gelmez. Bu bir tehdit değil, bir gerçektir.

### Uyarı
Bu repo ciddiye alınmamalıdır. Ama yine de ciddiye alın. Çünkü kahve makinesi izliyor.
